# Browser AI Agent

Автоматический агент на Python, который принимает задачу на естественном языке и выполняет её в реальном браузере через Playwright. Агент сам планирует шаги, выбирает инструменты и анализирует результат - пользователь только описывает цель словами.

![Python](https://img.shields.io/badge/Python-3.11-blue)
![Playwright](https://img.shields.io/badge/Playwright-automation-green)

## Что умеет

- Принимает задачу в естественном языке
- Сам разбивает её на шаги и выполняет в браузере
- Кликает, вводит текст, переходит по страницам, делает скриншоты
- Запоминает выполненные действия и не ходит по кругу
- Возвращает отчёт о проделанной работе

Пример задачи: «закажи пиццу в Яндекс Еде на мой адрес».

## Как это работает

Агент работает в цикле:

1. Пользователь вводит задачу текстом.
2. LLM получает задачу и текущее состояние страницы, решает, какой шаг сделать следующим.
3. Агент вызывает один из инструментов: `navigate`, `click_element`, `type_into_input`, `get_observation`.
4. Playwright выполняет действие в реальном браузере.
5. Агент получает обновлённое состояние страницы и повторяет цикл.
6. Цикл идёт, пока задача не будет решена или не станет очевидно, что дальше двигаться некуда.

По сути - это ReAct-агент, где LLM планирует, а Playwright даёт ему «руки» для взаимодействия с вебом.

## Установка

```bash
git clone https://github.com/9BUBBLE9/Browser_AI_agent.git
cd Browser_AI_agent

pip install -r requirements.txt
playwright install
```

## Запуск

1. Скопируй шаблон конфигурации и впиши свой ключ OpenAI:

```bash
cp .env_example .env
# OPENAI_API_KEY=sk-...
```

2. Запусти агента:

```bash
python main.py
```

3. Введи задачу, например:

```
Закажи Биг Спешал из яндекс еды на мой адрес
```

## Стек

- **Python 3.11**
- **Playwright** - автоматизация браузера
- **OpenAI API (GPT-4)** - принятие решений
- **python-dotenv** - конфигурация

## Ограничения

- Требует рабочий API-ключ OpenAI (платно).
- Зависит от качества LLM - в сложных сценариях может зациклиться или выбрать неверный элемент.
- Не обходит CAPTCHA и антибот-защиту.
- Работает только с сайтами, которые не блокируют автоматизацию.
